# 計画タブをスプレッドシートにつなぐ（GAS の更新手順）

家計簿アプリの「計画」タブ（旧お金計画）は、家計簿と同じスプレッドシートに保存します。
GAS を更新するまでは、計画はスマホの中にだけ保存され、計画タブに「保存できていません」と出ます。

## 手順（PC で 5 分ほど）

1. スプレッドシート「家計簿_Claude」を開き、拡張機能 › Apps Script を開く
2. 左の「ファイル」の ＋ › スクリプト で `plan` を作り、[`plan.gs`](plan.gs) の中身をそのまま貼り付けて保存する
3. `api.gs` の `doGet` と `doPost` の **先頭** に 1 行ずつ足して保存する

   ```js
   function doGet(e) {
     var r = planRouteGet_(e); if (r) return r;   // ← 追加
     // …ここから下は今までのまま…
   }

   function doPost(e) {
     var r = planRoutePost_(e); if (r) return r;  // ← 追加
     // …ここから下は今までのまま…
   }
   ```

4. デプロイ › デプロイを管理 › 鉛筆（編集）› バージョン「新バージョン」› デプロイ
   （URL は変わらないので、アプリ側の設定はそのまま）
5. アプリで 計画 › 計画の設定 › 「今すぐ同期する」を押す。シート「計画」「計画_月」「計画_設定」ができれば完了

## 合言葉について

`plan.gs` は家計簿と同じ合言葉（`api.gs` の `apiToken_()` が読むスクリプトプロパティ `API_TOKEN`）で確認します。
合言葉を別の名前で書いている場合は、`plan.gs` の `planTokenOk_` の中を書き換えてください。

## シートの形

| シート | 1 行の中身 |
|---|---|
| 計画 | 月・区分（収入／生活費／固定費／貯金／変動費）・有効・項目・種別・金額・支払日・メモ・ID・更新日時。生活費の金額はマイナス（差し引く項目）もある |
| 計画_月 | 月・変動費の入れ方（項目別／全体）・変動費（全体）・作成日時・更新日時・手取り（実績）・上振れの貯金割合（%）・生活費（オン／オフ）・毎月の貯金 |
| 計画_設定 | カテゴリなど（キーと値） |

アプリが保存するたびに 3 シートを書き直すので、シートを手で直した場合は、アプリで「今すぐ同期する」を押してから使ってください（アプリ側に未送信の変更があると、そちらが優先されます）。
